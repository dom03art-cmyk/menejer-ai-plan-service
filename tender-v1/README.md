# tender-v1 — тендерийн материалын модуль

`mongol-tender` скиллийн (v0.4) серверийн хувилбар. plan-v2, marketing-v1, org-v1-ийн ажиллаж буй кодыг өөрчлөхгүй, тэдгээрийн функцийг зөвхөн уншиж ашиглана: Claude дуудлага, Messenger, QPay, файл унших, Excel тооцоологч.

## Урсгал (Messenger)
1. **TENDER** товч. Үйлчилгээний тайлбар, үнэ болон ТББ илгээх холбоос `/u/tnd/<token>` очно. Төлбөрөөс өмнө агуулгыг уншихгүй.
2. **«Дууслаа»** дарна. Дараа нь багц асууна, төлбөр авна (QPay `kind: "tender"`; баримтаар бол админ `PAYOK|TND|<psid>`).
3. **A шат** — шинжилгээ:
   - файлуудыг уншина (org-v1/rawtext: PDF болон скан хуудсыг Claude үгчлэн хуулна, текстийг кэшилнэ);
   - A1 ТББ задлана;
   - олон багцтай бол багц сонгуулна;
   - хугацаа дууссан эсвэл барилгын шинжтэй бол зөвхөн шалгах жагсаалт илгээж, админд мэдэгдэнэ;
   - A2 асуулт гаргаж оролцогчид илгээнэ.
4. **Оролцогч хариулна.** Чатаар бичнэ; баримтаа холбоосоор эсвэл чатад шууд илгээнэ. **«✅ Бэлэн»** дарахад GAP шалгалт (Haiku) дутууг 1 удаа асууна. «Ингээд гарга» гэвэл шууд эхэлнэ.
5. **B шат** — материал:
   - B1 оролцогчийн өгөгдөл → B2 текст → хөдөлгүүр (engine/ = скиллийн lib; Excel-ийг plan-v2/xlsxCalc-аар тулгана);
   - Claude-ийн алдаа (`REQ_UNASSESSED`, `STATUS_CONFLICT`, `PROMISE_UNMET`, `METHODOLOGY_MISSING`, `TECH_COPIED` …) гарвал ≤2 удаа өөрөө засна;
   - оролцогчийн мэдээлэл дутуу бол (үнэ, доод үнэ, компанийн мэдээлэл, хүчинтэй хугацаа …) жагсаалтаар асууж, оролцогч дахин «Бэлэн» дарна.
6. **Хүргэлт.** Эхлээд `chat` (Дутуу / Анхаарах, үнэ, доод үнэ, хугацаа), дараа нь файлууд:
   - `01-shalgakh-jagsaalt.docx`
   - `02-tenderiin-material.docx`
   - `03-unii-zadargaa.xlsx`
   - `04-…-tusul.docx`
   
   Дараа нь сануулга илгээнэ. 14 хоногийн дотор 1 удаа үнэгүй «Дахин гаргах» эрхтэй. Нэг захиалгад B шатыг хамгийн ихдээ `TENDER_MAX_RUNS` (4) удаа ажиллуулна.

## Хамгаалалт
- **Унтраалга:** `TENDER_ENABLED=1` биш бол ажил үүсэхгүй, цэсэнд товч гарахгүй. `TENDER_ALLOW_PSIDS=<админ psid>` тохируулбал зөвхөн тэр psid туршина.
- **Нөөцийг булаалдахгүй:** бизнес төсөл, маркетинг, тайлангийн ажил явж байвал түүнийг хүлээнэ.
- **Хадгалалт:** Redis түлхүүрүүд `tnd:*` угтвартай (бусадтай давхцахгүй), 30 хоног хадгална.
- **Дахин асахад сэргээнэ:** SIGTERM үед тасарсан ажлын жагсаалтыг хадгалж, асахдаа дахин эхлүүлнэ. Мөн оролцогч бичихэд ажил явахгүй байвал дахин эхлүүлнэ.
- **Агуулгын шалгалт** (plan-v2/guard) зөвхөн оролцогчийн яриан дээр хийгдэнэ. ТББ нь төрийн баримт тул шалгахгүй.

## Орчны хувьсагч
`TENDER_ENABLED`, `TENDER_ALLOW_PSIDS`, `TENDER_PRICE` (өгөгдмөл 149900), `TENDER_MODEL` (өгөгдмөл WRITER), `TENDER_GAP_MODEL` (өгөгдмөл FAST), `TENDER_MAX_PARALLEL` (1), `TENDER_MAX_RUNS` (4), `TENDER_TTL_DAYS` (30), `TENDER_DRY` (1 = Facebook руу илгээхгүй).

## API (x-api-key)
- `GET /tender/status`
- `GET /tender/jobs/:id`
- `POST /tender/jobs {psid, kind: analyze|compose}`
- `GET /tender/case/:psid`
- `POST /tender/flow {psid, text, payload}` — Messenger-гүй туршилт

## Холбох өөрчлөлт (энэ салбарт бэлэн, deploy-оос өмнө батлуулна)
1. **server.js:** `try { app.use(require("./tender-v1")); } catch …` — 1 мөр.
2. **org-v1/flow.js** — алдааг try/catch-аар барьсан 3 өөрчлөлт:
   - `handle()`-ийн эхэнд tender-ийн `claims` → `handle`;
   - `admin()`-д `PAYOK|TND|`;
   - цэсэнд `TENDER_ENABLED=1` үед «Тендерийн материал» товч.
3. **Make 6206912:**
   - «Бусад үйлчилгээ» замын шүүлтүүрт `payload = TENDER` OR бүлэг нэмнэ;
   - мэндчилгээний (module 8) товчинд «Тендерийн материал / TENDER» нэмнэ.
   
   Админы `PAYOK|` шүүлтүүр хуучнаараа ажиллана.

## Туршилт
- `node tender-v1/test/engine-test.js` — 7 жишээ (скиллийн регресс).
- `node tender-v1/test/flow-test.js` — 25 шалгалт: бүтэн урсгал, олон багц, барилгын шинжтэй, хугацаа дууссан, өөрөө засах, дутууг асуух, цэс, унтраалга.
- `node tender-v1/test/hook-test.js` — org-v1 холбоос.
- org-v1/test/* — өөрчлөлтийн өмнө ба дараа бүгд амжилттай.

Бодит Claude-аар хийх туршилтыг Render дээр `TENDER_ALLOW_PSIDS=<админ>` тохиргоотойгоор хийнэ. Ингэхэд захиалагчдад нөлөөлөхгүй.
