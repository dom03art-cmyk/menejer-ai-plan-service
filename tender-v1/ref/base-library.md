# Суурь баримтын сан

Санаа: тендерт тогтмол оролцох компани баримтаа тендер зарлагдахаас **өмнө** нэг санд бэлэн байлгана. Тендер бүрт шинээр цуглуулахгүй, зөвхөн тухайн ТББ-ийн шаардлагаар шүүнэ. (Санааны эх: Г.Энх-Амгалан, «Тендер зарлагдахаас өмнө бэлэн байлгах 18 баримт бичиг», 2026. Текстийг хуулахгүй.)

## 1. Ангилал (слотын `category`)
| Код | Бүлэг | Слот (`key`) жишээ |
|---|---|---|
| A | Эрх зүй, цахим бэлэн байдал | `reg` улсын бүртгэл · `charter` дүрэм · `director` захирлын томилгоо/итгэмжлэл · `esign` тоон гарын үсэг, tender.gov.mn эрх · `license` тусгай зөвшөөрөл |
| B | Татвар, санхүү | `tax` татвар/НДШ өргүй · `court` шүүхийн лавлагаа · `fin_report` e-balance-д баталгаажсан санхүүгийн тайлан · `audit` аудитын дүгнэлт · `revenue` жил бүрийн борлуулалт · `credit` зээлийн мэдээллийн сангийн тодорхойлолт · `bank` банкны тодорхойлолт/зээлийн шугам |
| C | Туршлага | `contract` ижил төстэй гэрээ · `act` хүлээлгэн өгсөн акт · `reference` захиалагчийн тодорхойлолт |
| D | Хүний нөөц, техник | `staff_cv` гол ажилтны диплом, үнэмлэх, CV · `ndsh` НД-7, НД-8, НДШ лавлагаа · `labor_contract` хөдөлмөрийн гэрээ · `equipment` тоног төхөөрөмжийн өмчлөл/түрээс |
| E | Барааны техникийн нотолгоо | `catalog` каталог, техникийн хуудас · `certificate` чанарын гэрчилгээ · `manufacturer` үйлдвэрлэгч/дистрибьюторын эрх |
| L | Оролцогчийн өөрийн албан бичиг | `letter` (systems drafts — `letters[]`) |

## 2. Баримтын төлөв (дотоод бүртгэл — оролцогчид өнгөөр харуулахгүй)
- `uploaded` — файл ирсэн, Claude уншиж утгыг шалгасан (нэр, регистр, огноо зөрүүгүй).
- `missing` — шаардлагатай боловч алга → чатын «Дутуу» жагсаалтад.
- `esystem` — tender.gov.mn бусад сангаас (ХУР, НДШ, татвар, e-balance, шүүх) өөрөө шалгана; оролцогч урьдчилж шалгана.
Хүчинтэй хугацаатай баримтад `expires` заавал. Engine: эцсийн хугацаанаас өмнө дуусвал зогсооно, 60 хоногийн дотор дуусвал сануулна.

## 3. «Бэлэн» гэдэг нь
Файл байгаа төдийгүй: хүчинтэй, мэдээлэл бусад баримттай зөрүүгүй (компанийн нэр, хаяг, захирал), бүрэн (бүх хуудас, гарын үсэг), уншигдахуйц. Claude файл бүрийг уншиж эдгээрийг шалгана; зөрүү олдвол `note`-д бичнэ.

## 4. Туршлагын нотолгооны гинж
Гэрээ → нэхэмжлэх/хүргэлтийн баримт → хүлээлгэн өгсөн акт → төлбөрийн баримт эсвэл захиалагчийн тодорхойлолт. Гинж тасарсан бол «⚠️ дутуу».

## 5. Файлын нэршил (санал)
`<ангиллын код> <баримтын нэр> <он> <дуусах огноо>.pdf` — жишээ: `A05 Тусгай зөвшөөрөл 2026 2027-05-30.pdf`.

## 6. Бүтээгдэхүүний санаа (дараагийн шат)
- **Тендерийн бэлэн байдлын үнэлгээ** — оролцогч суурь баримтаа илгээнэ → слот бүрийн төлөв, дуусах хугацаа, хамгийн эрсдэлтэй 5 цоорхой бүхий тайлан. Тендерээс үл хамаарах тусдаа үйлчилгээ болж болно.
- **Давтан ашиглалт** — оролцогчийн суурь сангаа хадгалж, дараагийн тендерт зөвхөн шинэчлэх шаардлагатайг нэхэх (хадгалах хугацаа, зөвшөөрлийг тодорхой болгох).
- Захиалагчид өнгөт слот, хүснэгт харуулахгүй: дутуу болон сайжруулах зүйлийг **чатаар товч дугаарласан жагсаалтаар** өгнө (2026-10-14-ний шийдвэр).
